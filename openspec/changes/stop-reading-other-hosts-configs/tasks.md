The groups below land as one stacked chain, in order, and each commit evaluates on its own (design Migration Plan). Logs go under `logs/srohc-<group>-*`.
Every evaluation is named with its expected duration. An evaluation expected to exceed 5 minutes carries its notice here (expected duration, what it proves that a cheaper run cannot, and what waits on it), and that notice is given before the run starts.
**[operator]** marks a task that waits on the operator.
**[blocked: refactor oracle]** marks a task that needs `just drv-diff` from the refactor-oracle change (`establish-refactor-oracle`). This change lands directly after that one, so its parent revision is that change's tip; the task starts only once `just drv-diff` is available on the branch.
