Each group below is one stage and lands as one pull request; stages land in order, and each leaves `main` consistent on its own (design Migration Plan).
Every run is named with its size class (`references/test-sizes.md` of the `preferences-nix-checks-architecture` skill) and its expected duration; a run expected to exceed 5 minutes carries its notice here, and the agent returns it to the orchestrator, who gives it to the operator, before starting.
Runtime tests run on pyrite (`--store ssh-ng://pyrite.vanixiets.internal`, container tests with `--builders ''`); x86_64-linux builds on magnetite's store; logs under `logs/tsc-<stage>-*`.
**[operator]** marks a task that waits on the operator: an answer to a design Open Question, or approval of a run notice.
