## Why

The operator wants the prepared desktop to reclaim the bar's screen space and offer Zen Browser without changing browser defaults.

## What Changes

Enable `autoHide` on the existing default DankBar.
Install the pinned wrapped Zen package only for pyrite's cameron account.
Extend existing desktop verification without weakening greeter, audio or Bluetooth checks.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `machine-interface` (interface): declarative bar visibility and a host-local browser package.

The trust boundary separates evaluated configuration and built desktop entries from physical hover behavior and successful browser launch.

## Impact

Changes are limited to the DMS aggregate, Zen input and lock dependency, a new Zen aggregate, pyrite's cameron imports, desktop checks and this change unit.
No existing input pin, browser default, profile, service lifecycle or hardware policy changes.
Linear binding, publication, activation and archive remain deferred.
