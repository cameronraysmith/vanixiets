Size classes follow `references/test-sizes.md` of the `preferences-nix-checks-architecture` skill. A run expected to exceed 5 minutes is announced first with its expected duration, what it proves that a cheaper run cannot, and what waits on it.
Lessons carried from the earlier changes, which every group applies:
- A module's own list definitions merge after those of the modules it imports (nixpkgs `lib/modules.nix:602-611` and `:278`; A344, A352). Moving a definition from a host body into an imported aspect moves it earlier in every list it joins, unless it is written with `lib.mkAfter`.
- An attribute type or a `listOf deferredModule` wraps each module afresh and re-keys it; a `flake.modules` value imported from two parents is applied twice (A351).
- Allow-lists name exact attribute paths; a `may-change` entry is resolved to `changed` or removed before the next commit.
- Any `packages/docs` edit changes every docs-package check; any `testSizes.checks` entry changes `checks.x86_64-linux.fleet-alert`. A new check is `class = "medium"; measured = false;`.
- Every new or moved file is announced to the operator before any evaluation reads it, and formatted (`treefmt --fail-on-change` over it).
- Mutants run in a throwaway tree, never in `@`. Logs go under `logs/chca-<group>-*`.
