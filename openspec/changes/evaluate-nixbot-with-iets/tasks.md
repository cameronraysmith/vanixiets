Tasks marked **[operator]** are decisions or steps only the operator can take; present them through the `wizard` skill and stop. An agent MUST NOT tick an **[operator]** box.
Verification of nix-managed outputs is by `nix eval`, `nix build` of `.#checks.x86_64-linux.*` or `.#vmTests.x86_64-linux.*`, or a read on magnetite after deployment, as each task states; nothing is verified by reading source alone.
Long or output-heavy commands are captured: `<command> 2>&1 | tee logs/<identifier>-$(date +%Y%m%d-%H%M%S).log`.
Every pull request body carries `Part of CAM-111.`
This change adds no migration flag or one-shot conditional, so it carries no close-out task for one; the evaluator choice is one permanent line, not a flag.
