Tasks marked **[operator]** are steps only the operator can take (a decision, a host that must be online, or a key-store session); present them through the `wizard` skill and stop. An agent MUST NOT tick an **[operator]** box.
No command in this change prints a private key, a decrypted value or key-store item contents: decryption is checked by exit status or by a digest of the plaintext compared in the same shell, and key material moves only through pipes or `umask 077` temporary files under `$TMPDIR` that are removed in the same command.
Verification of nix-managed outputs is by `nix eval`, `nix build` or instantiation, or on the host after activation, as each task states; nothing is verified by reading source alone.
Long or output-heavy commands are captured: `<command> 2>&1 | tee logs/<identifier>-$(date +%Y%m%d-%H%M%S).log`.
