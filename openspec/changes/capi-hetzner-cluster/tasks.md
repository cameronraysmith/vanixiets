# Tasks

Each task names its verification.
Stage numbers S3, S4, S4b, S5 match proposal.md and ADR-007's revision-2 stage table; tasks within a stage depend on the preceding tasks of that stage unless stated.
S3 depends on `openspec/changes/k3s-nixos-vm-tests/tasks.md` S2 having passed (`vm-k3s-platform` green on the KVM developer host).
S4 depends on S3 and on the spend gate of design D10: Hetzner spend is approved in principle, and each flake revision that bills is released by `VANIXIETS_HETZNER_SPEND_APPROVED=<flake rev>` in the operator's shell; no effect calls the Hetzner Cloud API without it, and a green S3 releases nothing.
Every S4 task that bills carries the marker `[bills Hetzner]` and a cost line naming the billed resources; the amounts are Hetzner list prices at execution time and are recorded in the task's PR body (charter open question Q7).
S4b depends on S4 and bills nothing new (the gateway runs on M5).
S5 is deferred, GCP-only (design D11), and has no scheduled task.
Design Q1–Q7 are resolved (design.md Open Questions); no ambiguity gates a task here.
No task edits `kubernetes/clusters/local*`, `kubernetes/nixidy/`, `kubernetes/tests/local-k3d/`, `modules/apps/cluster/`, `.github/workflows/`, or the flake inputs, and every task's verification includes a `git diff --stat` check that those paths are absent.
Every effect and long-running command is captured with `2>&1 | tee logs/<name>-$(date +%Y%m%d-%H%M%S).log`.
