The change lands after register-fleet-obligations (whose tip is its parent) and before compose-hosts-from-cohesive-aspects, as one pull request of one commit: the groups share the user-service and host files, are not separately shippable, and a drvPath diff costs about 16 minutes. Each group keeps its own evidence by evaluation against the task 1.2 baselines. `just drv-diff` runs once, from the parent to the commit (task 9.1), and again at the merged head (task 9.6); the implementer returns its command to the operator rather than running it.
Verification is by evaluation (`nix eval`), by building the named checks (`nix build`), or by measurement (`just eval-cost`); each task says which. Reading the source is never the verification for a nix-managed output.
Size classes follow `references/test-sizes.md` of the `preferences-nix-checks-architecture` skill. A run expected to exceed 5 minutes is announced first with its expected duration, what it proves that a cheaper run cannot, and what waits on it.
Mutants run in a throwaway tree, never in `@`. Logs go under `logs/dhuro-<group>-*`.
