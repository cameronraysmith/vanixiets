Verification modes are named per task: **eval** (`nix eval`), **build** (`nix build`, including deliberate mutants that must fail), or **delivered** (the activated path on a host). Reading the source is never the verification. `COMPOSE` denotes a fresh `nix build .#apm-skills-compose --no-link --print-out-paths`; `BASE` denotes the same build at the change's parent commit, kept for comparison.
